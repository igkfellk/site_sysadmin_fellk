# Топ-5 подов по потреблению CPU

**Задача:** быстро найти «горячие» поды в кластере.

**Запрос:**

```promql
topk(5, sum by (pod) (rate(container_cpu_usage_seconds_total{container!=""}[5m])))
```

**Почему работает:** `rate(...[5m])` считает среднюю скорость роста счётчика за 5 минут, `sum by (pod)` суммирует по контейнерам внутри пода, `topk(5, ...)` оставляет пять самых больших значений.
