# Быстрый снимок трафика по порту

**Проблема:** сервис не отвечает, нужно понять, доходят ли пакеты.

**Команда:**

```bash
sudo tcpdump -i any -nn port 443 -c 20
```

**Почему работает:** `-i any` слушает все интерфейсы, `-nn` не резолвит имена (быстрее), `-c 20` останавливается после 20 пакетов. Если пакеты есть в обе стороны — сеть жива, проблема в приложении; если нет — смотри firewall/маршруты.
