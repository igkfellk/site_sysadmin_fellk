# Как найти, что съело диск

**Проблема:** `df -h` показывает 100%, но непонятно куда делось место.

**Диагностика:**

```bash
sudo journalctl --disk-usage          # сколько занимает журнал
sudo du -xh / 2>/dev/null | sort -rh | head -20   # топ-20 папок
```

**Решение:**

```bash
sudo journalctl --vacuum-size=200M    # обрезать журнал до 200 МБ
```

**Почему работает:** `journalctl --vacuum-size` удаляет старые записи журнала, оставляя только последние 200 МБ. `du -x` не переходит на другие файловые системы (важно для `/proc`, `/sys` и примонтированных дисков).
